🗳️ Secure Election Record Manager

Technology for Transparent, Fair & Fraud-Free Elections in India

🇮🇳 Our Mission: Stop False Voting

False or duplicate voting has long been a major concern during elections in India. The Secure Election Record Manager is designed to help identify, prevent, and eliminate fraudulent voter entries through advanced data verification and secure record management.

By securely storing and transferring verified voter data — including Aadhar numbers, photos, and gender information — this system helps election authorities ensure that each citizen votes only once and that every vote counted is genuine.

🔍 Overview

The Secure Election Record Manager is a Java Swing + MySQL based desktop application built to safeguard election-related citizen data. It ensures data accuracy, secure authentication, and transparent record movement between verified and secure databases.

⚙️ Core Features

🔒 Secure Admin Access

Only authorized personnel with the correct password can operate the application, reducing insider threats.

🧾 Verified Data Movement

Records are securely transferred from info to info_copy tables only after validation.

🧠 Anti-Fraud System

By storing Aadhar-linked voter details with images, the app helps prevent duplicate or fake entries.

📊 Live Record Tracking

Displays real-time counts of verified, moved, and remaining records — ensuring full transparency.

🚫 Operation Lock

System cannot be closed or used further until secure movement is confirmed — ensuring compliance and accountability.

🔐 Data Encryption

All database operations occur via encrypted JDBC connections, protecting sensitive voter data.

💡 Benefits to the Election System

  • Enhances trust and transparency in the voting process
  • Prevents false or duplicate votes through strict record validation
  • Helps Election Commission maintain clean and verified databases
  • Reduces manual verification errors with automated data checks
  • Supports Digital India initiatives for safe, paperless governance
  • Ensures only legitimate and verified citizens are allowed to vote

🧠 Technologies Used

☕ Java Swing

For an intuitive and efficient desktop interface for election officers.

🗄️ MySQL Database

🇮🇳 Designed for India

📘 Manual Database Setup Instructions

  1. Install and start MySQL Server (default port 3306).
  2. Download and open setup.sql.
  3. Run it in MySQL Command Line or phpMyAdmin to create the database.
  4. Ensure your MySQL username and password match the ones in your Java app.
